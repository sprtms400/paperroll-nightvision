# paperroll-nightvision

휴지심과 라즈베리파이로 간단하게 만든 야간투시경이다.

![동작 사진](nvg.png)

---

# 개요

## 1. 어떤 문제를 해결하려 했나요?

야간투시경은 비싸다. 원리는 단순한데 — 어두운 데서도 빛을 받아들여 화면에 띄우는 것 — 완제품은 수십만 원부터 시작한다.

직접 만들면 얼마나 나올까 싶었다. 문제는 케이스였다. 눈에 대는 통이 있어야 하고, 그 통은 화면 크기에 맞아야 하고, 옆에서 빛이 새면 안 된다. 3D 프린터로 뽑자니 설계부터 출력까지 며칠이다.

## 2. 어떻게 되었나요

휴지심이 그 조건을 다 만족했다. 지름이 원형 LCD와 얼추 맞고, 속이 비어 있고, 얼굴에 대기 좋은 길이다.

부품을 휴지심 안에 넣고 고정했더니 동작했다. 사진이 그 결과다.

## 3. 향후 과제

지금은 카메라 영상을 그대로 흘려보내기만 한다. 저조도 보정을 넣으면 더 잘 보일 것이고, 적외선 LED를 달면 완전한 암흑에서도 쓸 수 있다.

# 상세

## 1. 기존 문제 설정

**야간투시가 되려면 적외선을 받아야 한다.** 일반 카메라는 렌즈 안쪽에 적외선 차단 필터가 있다. 사람 눈에 안 보이는 적외선을 걸러서 사진 색을 자연스럽게 만드는 부품이다. 이게 있으면 어두운 데서 아무것도 안 잡힌다.

**눈에 대고 볼 통이 필요하다.** 화면만 있으면 야간투시경이 아니다. 눈을 화면에 붙이고 주변 빛을 막아야 어두운 화면이 보인다.

## 2. 해결방안 제시

**IR 차단 필터를 떼어낸다.** 카메라 모듈을 분해해 렌즈 안쪽 필터를 제거하면 적외선까지 받아들인다. 어두운 데서 형체가 잡히는 게 이 덕분이다.

**케이스는 휴지심으로 대신한다.** 설계하고 출력할 것 없이 바로 만들어볼 수 있다.

## 3. 구현 상세

### 구성품

- 라즈베리파이 제로
- 라즈베리파이 번들 카메라 모듈 (적외선 차단 필터 제거)
- GC9A01 원형 LCD 240x240 — [gc9a01-overlay](https://github.com/sprtms400/gc9a01-overlay)
- 18650 배터리
- 휴지심

### 개요도

```
                 ┌───────────────┐
                 │  GC9A01 LCD   │   240x240 원형
                 └───────┬───────┘
                         │ SPI
                 ┌───────┴───────┐         ┌──────────────────┐
                 │  라즈베리파이  ├── CSI ──┤   카메라 모듈     │
                 │      제로      │         │  (IR 필터 제거)   │
                 └───────┬───────┘         └──────────────────┘
                         │ 5V
                 ┌───────┴───────┐
                 │  18650 배터리  │
                 └───────────────┘

              ─────── 위 전부가 휴지심 안에 ───────
```

### 화면에 띄우는 방법

세 가지를 시도한 흔적이 코드에 남아 있다.

| 파일 | 방법 |
|---|---|
| `main.py` | picamera2 기본 프리뷰 (모니터 연결 전제) |
| `main_withocv2.py` | OpenCV 창으로 출력 |
| `directly_right_yhrough.py` | 프레임버퍼 `/dev/fb1` 에 직접 쓰기 |
| `simple_display_control.py` | GC9A01 드라이버로 텍스트 출력 테스트 |

## 4. 한계점

- 저조도 보정이 없다. 카메라가 받은 걸 그대로 흘려보낸다.
- 적외선 LED가 없어서 완전한 암흑에서는 안 보인다. 약한 빛이라도 있어야 한다.
- 위 네 파일이 통합되어 있지 않다. 각각 다른 출력 방법을 시도한 것들이다.
- 휴지심이라 튼튼하지 않다. 물에 젖으면 끝이다.
